## ⏱️ Complexity Analysis

While solving problems, I focus on understanding:

```text
Time Complexity
Space Complexity
Brute Force Approach
Optimized Approach
```

The goal is not just to make a program work, but to understand **why it works and how it can be improved**.

## 🧩 Problem Solving Approach

For every problem, I try to follow these steps:

1. Understand the problem
2. Find a simple/brute-force solution
3. Analyze its complexity
4. Look for possible optimizations
5. Implement the optimized solution
6. Test with different inputs
